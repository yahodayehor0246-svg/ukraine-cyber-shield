# UKRAINE CYBER SHIELD — API сервер

Це **серверний API**, а не Android-додаток. Він надає спільні API-маршрути для багатьох встановлених додатків.

## Потрібні змінні середовища в Railway

- `DATABASE_URL` — Railway PostgreSQL автоматично надає після додавання PostgreSQL та підключення змінної.
- `ADMIN_KEY` — довгий випадковий секретний ключ адміністратора. Не публікуй його і не вставляй у код Android-додатка.
- `PORT` — Railway встановлює автоматично.

## API

- `GET /api/health` — перевірка сервера і бази.
- `POST /api/check` — JSON: `{"url":"https://example.com"}`.
- `POST /api/report` — JSON: `{"url":"https://example.com"}`; повідомлення потрапляє в очікування.
- `GET /api/threats` — список підтверджених доменів.
- `GET /api/admin/reports` — очікувані повідомлення, заголовок `x-admin-key`.
- `POST /api/admin/reports/ID/decision` — JSON `{"decision":"confirmed"}` або `{"decision":"rejected"}`, заголовок `x-admin-key`.

## Важливі обмеження безпеки

Перевірка виконується лише над текстом URL. Сервер не відкриває і не завантажує сайти. Повідомлення користувачів не стають підтвердженими загрозами автоматично. Це початковий MVP, а не антивірус і не гарантія виявлення фішингу.

## Розгортання на Railway

1. Завантаж файли в GitHub-репозиторій.
2. У Railway створи проєкт і розгорни цей репозиторій.
3. Додай PostgreSQL у тому самому Railway-проєкті.
4. Підключи `DATABASE_URL` до сервісу API через змінні PostgreSQL / reference variable.
5. Додай `ADMIN_KEY` як секретну змінну сервісу.
6. Запусти Deploy. Перевір `https://ТВОЯ-АДРЕСА/api/health`.

Не додавай ADMIN_KEY у HTML або APK. Для адміністрування використовуй тільки захищений приватний інструмент.
